# PROMASTER ONE

リファレンスベース・マスタリングVSTプラグイン

## ダウンロード方法

1. 上の「Actions」タブをクリック
2. 緑のチェックマークがついたビルドをクリック
3. 下の「Artifacts」から `PROMASTER-ONE-VST3-Windows` をダウンロード

## インストール

1. ダウンロードしたZIPを解凍
2. `PROMASTER ONE.vst3` を `C:\Program Files\Common Files\VST3\` にコピー
3. DAW（Cakewalk等）でプラグインをスキャン

## 機能

- 8バンド・スペクトラムアナライザー
- リファレンストラック解析
- ワンクリック「ADJUST」ボタン
- 4種類のプリセット（Pop, Rock, Jazz, Electronic）
- 日本語/英語サジェスチョン
